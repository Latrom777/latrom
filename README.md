# Аудит Яндекс Директа — бесплатный скилл для Claude

Проверьте свой рекламный кабинет Яндекс Директа за 15 минут: куда уходит бюджет, какие запросы и площадки РСЯ сливают деньги, что не так с настройками и объявлениями. На выходе — понятный отчёт, готовые минус-слова, список площадок для запрета и план правок.

**Ничего не меняет в вашем кабинете** — только смотрит и советует. Пароль от Яндекса скилл никогда не спрашивает.

## Как пользоваться

### 1. Скачайте архив

[**⬇ yandex-direct-audit.zip**](../../releases/latest/download/yandex-direct-audit.zip) — архив не распаковывайте.

### 2. Установите в Claude

**Claude.ai (сайт или приложение)** — нужен платный тариф (Pro, Max, Team или Enterprise):
1. Настройки → «Возможности» (Capabilities) → включите выполнение кода и создание файлов.
2. Там же, в разделе «Навыки» (Skills) → «Загрузить навык» → выберите `yandex-direct-audit.zip`.
3. Убедитесь, что навык включён.

**Claude Code:** распакуйте архив в `~/.claude/skills/` (должно получиться `~/.claude/skills/yandex-direct-audit/SKILL.md`).

### 3. Напишите в новом чате

> Хочу проверить свою рекламу в Яндекс Директе

Claude предложит два способа:

| | Быстрый | Полный через API |
|---|---|---|
| Что нужно | скачать 3–4 отчёта из Директа и прислать в чат | один раз оформить доступ к API (Claude поможет, через 2–3 дня можно пользоваться) |
| Время | ~15 минут | первый раз — несколько дней ожидания одобрения от Яндекса, дальше — минуты |
| Точность | хорошая | лучше: видит все объявления, расширения, настройки |
| Повторять каждую неделю | вручную | одной командой |

Начните с быстрого, а если понравится — подключайте API.

## Что проверяется

- Куда уходит бюджет: кампании, поиск против РСЯ, расход без заявок.
- Нецелевые поисковые запросы → готовый список минус-слов.
- «Мусорные» площадки РСЯ (игры, приложения, случайные клики) → список для запрета.
- Ключевые фразы, которые тратят деньги без результата.
- Настройки: стратегии, цели Метрики, регионы, минус-слова, бюджеты.
- Объявления: быстрые ссылки, уточнения, картинки, второй заголовок, UTM-метки, отклонения.

Пороги взяты из общей практики. Финальное решение по правкам — за вами или вашим специалистом.

## Безопасность и данные

- Логин, пароль, SMS-коды и капчу вводите только вы. Скилл их не спрашивает.
- Без вашего «да» ничего не создаётся и не отправляется.
- В кабинет ничего не пишется, только чтение.
- Если подключали API: после аудита токен можно отозвать в [настройках безопасности Яндекс ID](https://id.yandex.ru/security). Claude напомнит.
- Ваши отчёты обрабатывает Claude в рамках вашего аккаунта Anthropic. Скилл никуда их не отправляет.

## Частые вопросы

**Claude пишет, что не может подключиться к api.direct.yandex.com.** В claude.ai песочнице кода может быть закрыт доступ в интернет. Разрешите в настройках выполнения кода домен `api.direct.yandex.com` (или доступ в интернет) либо используйте быстрый аудит по отчётам.

**Яндекс отклонил заявку на API.** Пришлите Claude причину отказа: в скилле есть разбор частых причин и готовые тексты для повторной заявки.

**Я агентство, у меня много клиентов.** Подходит: при выгрузке через API укажите логин клиента. Claude спросит.

**Это официальный инструмент Яндекса?** Нет. Это независимый открытый проект, используется официальный [API Яндекс Директа](https://yandex.ru/dev/direct/).

## Для разработчиков

```
yandex-direct-audit/
├── SKILL.md                     # главная инструкция для Claude
├── references/
│   ├── manual-export.md         # какие отчёты скачать (быстрый режим)
│   ├── oauth-app.md             # приложение на Яндекс OAuth
│   ├── access-request.md        # заявка на доступ к API + шаблоны текстов
│   └── audit-checklist.md       # чек-лист и формат отчёта
└── scripts/
    ├── direct_fetch.py          # выгрузка через API v5 + Reports (только чтение, зависит только от requests)
    └── setup_access.py          # браузерный агент на browser-use для оформления доступа
```

- Собрать архив: `./build.sh` → `dist/yandex-direct-audit.zip`.
- Релиз: поменяйте `yandex-direct-audit/VERSION`, создайте тег `vX.Y.Z` — GitHub Actions соберёт архив и прикрепит его к релизу.
- Браузерный помощник без Claude-браузера:
  ```bash
  pip install browser-use && export ANTHROPIC_API_KEY=...
  python yandex-direct-audit/scripts/setup_access.py --step app
  python yandex-direct-audit/scripts/setup_access.py --step request --client-id <ClientID>
  python yandex-direct-audit/scripts/setup_access.py --step token --client-id <ClientID>
  ```
- Выгрузка вручную: `YANDEX_DIRECT_TOKEN=... python yandex-direct-audit/scripts/direct_fetch.py --days 30`
