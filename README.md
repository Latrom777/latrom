# Аудит Яндекс Директа для онлайн-школ и инфобизнеса от SibLead.ru

Бесплатный скилл для Claude. Проверьте рекламу своей школы или курса в Яндекс Директе за 15 минут и получите **оценку от 0 до 100**:

- **вся воронка по каждой кампании**: регистрации → дошли до вебинара → заявки → продажи. Доходимость, цена дошедшего, CAC, ROMI и ДРР, всё сопоставляется по UTM;
- **какие кампании приносят продажи**, а какие дают только дешёвые регистрации, которые не доходят до вебинара;
- **где теряются деньги в воронке**: в рекламе, на доходимости, на вебинаре или в продажах;
- куда уходит бюджет: «сливы» курсов, складчины, госпрограммы, мусорные площадки РСЯ;
- что не так с целями, стратегиями, ретаргетингом и объявлениями;
- готовые минус-слова, список площадок для запрета, шаблон UTM и план правок.

**Ничего не меняет в кабинете и не просит пароль.** Вы присылаете отчёты из Директа и, если хотите, продажи — Claude всё разбирает.

## Как пользоваться

### 1. Скачайте архив

[**⬇ siblead-direct-audit.zip**](../../releases/latest/download/siblead-direct-audit.zip) — распаковывать не нужно.

### 2. Установите в Claude

**Claude.ai (сайт или приложение).** Нужен платный тариф: Pro, Max, Team или Enterprise.
1. Настройки → «Возможности» (Capabilities) → включите выполнение кода и создание файлов.
2. Там же «Навыки» (Skills) → «Загрузить навык» → выберите `siblead-direct-audit.zip`.
3. Проверьте, что навык включён.

**Claude Code.** Распакуйте архив в `~/.claude/skills/`, чтобы получилось `~/.claude/skills/siblead-direct-audit/SKILL.md`.

### 3. Напишите в новом чате

> Сделай аудит моего Яндекс Директа

Claude подскажет, какие отчёты скачать из Директа, задаст несколько вопросов о продукте и воронке и выдаст отчёт с оценкой.

**Данные воронки** — по желанию, но с ними аудит в разы точнее: регистрации, дошедшие до вебинара, заявки, продажи. Можно прислать не все шаги. Подойдёт:
- выгрузки из **GetCourse**, **Bizon365**, Prodamus, Тильды;
- сделки из **AmoCRM / Bitrix24**;
- **ссылка на Google Таблицу**;
- даже скриншот отчёта.

Нужны UTM-метки (отдельными колонками или внутри ссылки), для продаж — сумма и статус. Контакты используются только для удаления дублей и в отчёт не попадают.

Если у вас уже есть токен API Директа, можно обойтись без ручных выгрузок.

## Как считается оценка

45 проверок в семи категориях. У каждой проверки своя важность: критичная, высокая, средняя или низкая.

| Категория | Вес |
|---|---|
| Метрика и цели | 17% |
| Воронка и продажи | 25% |
| Слив бюджета | 18% |
| Структура и стратегии | 10% |
| Ключевые фразы и запросы | 12% |
| Объявления | 12% |
| Таргетинг | 6% |

Грейды: **A** 90–100 · **B** 75–89 · **C** 60–74 · **D** 40–59 · **F** <40.

Проверки, для которых нет данных, в оценку не идут, и в отчёте это видно. Без данных воронки оценка считается без категории «Воронка и продажи». Пороги — ориентир из практики, финальное решение по правкам за вами или вашим специалистом.

## Безопасность и данные

- Скилл не просит логин, пароль или доступ к кабинету. Работает только с отчётами, которые вы сами прислали.
- Контакты клиентов из файла продаж (email, телефон, имя) удаляются автоматически и не попадают в отчёт. Надёжнее удалить их до отправки.
- Отчёты обрабатывает Claude в рамках вашего аккаунта. Скилл никуда их не отправляет.
- Если давали токен API — после аудита его можно отозвать в [настройках безопасности Яндекс ID](https://id.yandex.ru/security).

## SibLead.ru

Для онлайн-школ с бюджетом от 200 000 ₽/мес команда **[SibLead.ru](https://siblead.ru)** проводит консультации по эффективным воронкам в нише и AI-аудит вебинаров по 65+ параметрам. Пришлите отчёт аудита — начнём с ваших цифр.

## Для разработчиков

```
siblead-direct-audit/
├── SKILL.md                     # инструкция для Claude
├── references/
│   ├── manual-export.md         # какие отчёты и данные воронки нужны
│   ├── audit-checklist.md       # 45 проверок, пороги, словари — источник правды для оценки
│   ├── report-template.md       # формат отчёта
│   └── cta.md                   # блок SibLead.ru: варианты по бюджету (редактируйте здесь)
└── scripts/
    ├── score.py                 # оценка 0–100 по статусам проверок (читает таблицу из чек-листа)
    ├── funnel.py                # воронка × кампании по UTM: доходимость, цена шагов, CAC, ROMI, ДРР
    └── direct_fetch.py          # выгрузка через API v5 + Reports, только чтение
```

- Собрать архив: `./build.sh` → `dist/siblead-direct-audit.zip`.
- Релиз: поднимите `siblead-direct-audit/VERSION` и создайте тег `vX.Y.Z` — GitHub Actions прикрепит архив к релизу.
- Чтобы поменять проверки или пороги, правьте таблицу в `audit-checklist.md`. `score.py` подхватит изменения сам.

Методика частично основана на открытых проектах [ai-hub-open/yandex-direct-audit](https://github.com/ai-hub-open/yandex-direct-audit) (Apache-2.0) и [Silverov/yandex-direct-skill](https://github.com/Silverov/yandex-direct-skill) (MIT). Подробности — в [NOTICE](siblead-direct-audit/NOTICE). Лицензия — MIT. Не является официальным продуктом Яндекса.
