# Как выгрузить Telegram

Давай человеку по одному шагу и жди подтверждения.

## Полная выгрузка личных чатов (рекомендуется)

Нужен Telegram Desktop на компьютере (Windows, macOS, Linux). В мобильном приложении выгрузки нет.

1. Откройте Telegram Desktop → **Настройки** → **Продвинутые настройки** → **Экспорт данных из Telegram**.
2. Отметьте только **Личные чаты**. Группы, каналы и ботов не отмечайте.
3. Снимите галочки с фото, видео, голосовых, стикеров и файлов — нужен только текст.
4. Формат: **Машиночитаемый JSON**.
5. При желании задайте период («С» и «По»), например с 2022 года.
6. Нажмите **Экспортировать**. Telegram может попросить подтвердить экспорт на телефоне. Иногда в целях безопасности экспорт становится доступен только через 24 часа — это нормально.
7. В папке выгрузки будет файл **result.json**. Пришлите его.

Если человек ведёт продажи с нескольких аккаунтов (свой, менеджера, ассистента) — пусть выгрузит каждый и пришлёт все файлы. Объединяй их в одну базу, в колонке «Аккаунт» указывай, с какого аккаунта шла переписка.

## Один чат

Если нужно разобрать один-два чата: откройте чат → меню «⋮» → **Экспорт истории чата** → снимите медиа → формат **JSON**.

## Если файл большой

- Сначала уберите медиа и сократите период.
- Заархивируйте result.json в ZIP — текст сжимается в 5–10 раз.
- Если сайт или приложение не принимает файл по размеру: выгрузите по годам (несколько экспортов с разными периодами) и присылайте по очереди, или работайте в Claude Code, где ограничений на размер нет.

## Безопасность

- Выгрузка содержит личные переписки. Она остаётся в рамках аккаунта человека, скилл никуда её не отправляет.
- Перед отправкой можно удалить из выгрузки чаты, которые не хочется показывать: это обычный JSON, но проще задать период и не отмечать лишние типы чатов.
