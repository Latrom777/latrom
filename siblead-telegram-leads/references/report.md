# Результат

## 1. Таблица

Если среда умеет создавать файлы — сохрани `leads.xlsx` (или `leads.csv`), отсортированный по баллу. Иначе — таблицей в ответе, только группы A и B.

Колонки:

| Группа | Балл | Имя | ID чата | Аккаунт | Статус | Теплота | Запрос | Бюджет / сроки | На чём остановились | Последнее сообщение | Кто писал последним | Повод вернуться | Черновик |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

- «Последнее сообщение» — дата.
- «Аккаунт» — только если выгрузок несколько.
- «Черновик» — только для группы A.
- Телефоны — только если человек попросил.

## 2. Сводка в чате

```
Разобрал <N> личных чатов за <период>.
Лидов: <L> · не лиды: <X> · партнёры: <P>

A — написать на этой неделе: <a>
B — в течение месяца: <b>
C — в рассылку: <c>

Мы не ответили: <k> человек — начните с них.
Купили раньше: <m> — им проще всего продать снова.
```

Затем:
- **Топ-20 «кому написать первым»** — имя, балл, запрос, на чём остановились, одной строкой каждый.
- **Частые запросы** — 3–5 пунктов с количеством.
- **Частые причины, почему не купили** — 3–5 пунктов с количеством. Это готовые подсказки для оффера.

## 3. Черновики для группы A

Правила:
- Лично, по имени, на «вы», если в переписке было «вы».
- Первая фраза напоминает конкретную точку из прошлой переписки: «Вы спрашивали про трафик на вебинар весной».
- Вторая — повод: что изменилось (новый продукт, поток, кейс, цена, бесплатный разбор).
- Третья — простой вопрос, на который легко ответить: «Актуально сейчас?»
- До 400 знаков. Без «уникальное предложение», капса, давления и скидок, которых человек не называл.
- Для статуса «Мы не ответили» — начни с извинения за паузу одной фразой.

Пример:

> Анна, добрый день! В марте вы спрашивали про трафик на вебинар с бюджетом около 300 тысяч и хотели вернуться после запуска. Мы сейчас запускаем подписчиков в Max из Яндекса — дешевле, чем было в Telegram. Актуально для вашего следующего потока?
