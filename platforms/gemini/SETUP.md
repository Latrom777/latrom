# ИИ-аудитор Директа от SibLead.ru — Gemini (Gem)

Есть два способа:
- **SibLead создаёт Gem один раз и делится им по ссылке**, если в вашем аккаунте доступен шаринг Gem. Рекомендуется.
- Каждый собирает Gem себе сам по этой инструкции.

## Создание Gem

1. Откройте [gemini.google.com](https://gemini.google.com) → **Gems** (Обзор Gem) → **Новый Gem**.
2. **Название:** `Аудит Яндекс Директа для онлайн-школ — SibLead`
3. **Описание** (если есть поле): `Бесплатный аудит Директа с оценкой 0–100: воронка по кампаниям, слив бюджета, план правок.`
4. **Инструкции:** вставьте целиком содержимое `instructions.md` из этой папки.
5. **Знания** (Knowledge): добавьте 6 файлов из папки `knowledge/`: `audit-checklist.md`, `data-handling.md`, `manual-export.md`, `report-template.md`, `cta.md`, `browser-download.md`. Лимит — 10 файлов. Если `.md` не загружается, переименуйте файлы в `.txt` или положите их в Google Диск и добавьте оттуда.
6. **Сохранить.** Справа можно сразу проверить: напишите «Сделай аудит моего Директа».
7. **Поделиться** (если доступно): меню Gem → «Поделиться» → доступ по ссылке. Gem открывается у людей с аккаунтом Google.

## Что учесть

- Gemini читает xlsx и csv, которые человек прикрепил в чат, и умеет считать по ним. Для больших выгрузок (тысячи строк поисковых запросов) лучше CSV.
- Ссылки на Google Таблицы Gemini открывает, если у человека есть к ним доступ. Иначе — попросить файл.
- Сам Gem не скачивает отчёты из Директа: он даёт человеку инструкцию из `manual-export.md`.

## Проверка перед раздачей

1. Загрузите реальные выгрузки одной школы, проверьте отчёт, оценку и блок SibLead.
2. Повторите на том же наборе 2–3 раза: оценка должна совпадать или отличаться на несколько баллов.

## Обновление

Gems → ваш Gem → «Изменить»: замените файлы в «Знаниях» и, если менялся `instructions.md`, текст инструкций → «Сохранить».
