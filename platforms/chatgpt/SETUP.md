# ИИ-аудитор Директа от SibLead.ru — ChatGPT (Custom GPT)

Есть два способа:
- **SibLead создаёт GPT один раз и раздаёт ссылку.** Людям ничего настраивать не нужно. Рекомендуется.
- Каждый собирает GPT себе сам по этой инструкции.

Создавать GPT можно на платных тарифах ChatGPT (Plus, Pro, Team, Enterprise). Пользоваться готовым GPT по ссылке можно и на бесплатном тарифе, но с лимитами.

## Создание GPT

1. ChatGPT → «GPTs» (Explore GPTs) → **Create** → вкладка **Configure**.
2. **Name:** `Аудит Яндекс Директа для онлайн-школ — SibLead`
3. **Description:** `Бесплатный аудит Директа с оценкой 0–100: воронка регистрации → вебинар → заявки → продажи по каждой кампании, слив бюджета, план правок.`
4. **Instructions:** вставьте целиком содержимое `instructions.md` из этой папки (около 4 000 символов при лимите 8 000).
5. **Conversation starters:**
   - `Сделай аудит моего Яндекс Директа`
   - `Какие отчёты скачать из Директа для аудита?`
   - `Вот мои выгрузки из Директа и GetCourse — разбери`
   - `Почему у меня дешёвые регистрации, но нет продаж?`
6. **Knowledge:** загрузите все 11 файлов из папки `knowledge/`: `report.html` (дизайн PDF), 4 модуля (`minus-words.md`, `placements.md`, `structure.md`, `goals.md`), `data-collection.md`, `data-handling.md`, `audit-checklist.md`, `report-template.md`, `self-recovery.md`, `cta.md`.
7. **Capabilities:**
   - ✅ **Code Interpreter & Data Analysis** — обязательно, без него GPT не прочитает xlsx/csv и не посчитает воронку;
   - ✅ **Web Search** — по желанию, нужен для ссылок на Google Таблицы;
   - ✅ **Canvas** — по желанию, удобно для отчёта;
   - ❌ Image Generation — не нужен.
   - Память ChatGPT, если включена у человека, позволит GPT помнить найденные обходы между чатами этого человека.
8. **Create** → выберите доступ:
   - **Anyone with the link** — для раздачи по ссылке;
   - **GPT Store** — чтобы GPT находили в поиске (нужен подтверждённый профиль автора; в профиле можно указать сайт siblead.ru).

## Браузер

Обычный GPT в браузер не ходит. Если у человека есть **режим агента** ChatGPT, агент может собрать все данные сам (путь А из `data-collection.md`): человек входит в Яндекс через «Взять управление», агент работает только на чтение. Без режима агента GPT ведёт человека по пошаговой инструкции (путь Б).

## Проверка перед раздачей

1. Откройте GPT и напишите «Сделай аудит моего Директа» — он должен задать вопросы и попросить отчёты.
2. Загрузите реальные выгрузки одной школы, проверьте отчёт, оценку и блок SibLead.
3. Повторите на том же наборе 2–3 раза: оценка должна совпадать или отличаться на несколько баллов.

## Обновление

При изменении методики замените файлы в Knowledge и, если менялся `instructions.md`, текст в Instructions → **Update**. Ссылка на GPT останется прежней.
