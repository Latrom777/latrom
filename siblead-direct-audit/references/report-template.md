# Формат отчёта

Пиши для владельца бизнеса: простыми словами, с цифрами, без жаргона. Объясняй термины при первом упоминании, например: «РСЯ (реклама на сайтах-партнёрах Яндекса)». Не обещай рост заявок в процентах — показывай, сколько денег можно перестать терять.

```markdown
# Аудит Яндекс Директа

<Школа / эксперт / продукт> · реклама <дд.мм – дд.мм>, продажи <дд.мм – дд.мм> · данные: <выгрузки / API>, <продажи: источник или «без продаж»>

## Оценка: <N>/100 — <грейд> (<статус>)

<таблица категорий из score.py как есть>

<1–2 предложения: главное, что нужно знать.>

## Деньги

| | |
|---|---|
| Расход за период | … ₽ |
| Клики · CTR · средняя цена клика | … · …% · … ₽ |
| Лиды (регистрации / заявки) · CPL | … · … ₽ |
| Продажи · выручка · CAC (если есть продажи) | … · … ₽ · … ₽ |
| ROMI · ДРР (по выручке) | …% · …% |
| **Под риском (оценка)** | **~… ₽ (…% бюджета)** |

Из чего складывается «под риском»: нецелевые запросы ~… ₽, мусорные площадки ~… ₽, фразы и кампании без конверсий ~… ₽. Суммы не задваивай: одна и та же трата не должна попадать в две строки.

## Окупаемость по кампаниям

Только если есть файл продаж. Таблица из `sales_summary.md`: кампания, расход, лиды, продажи, выручка, ROMI, ДРР, CAC. Отсортируй по расходу и отметь:
- 🟢 окупается (ROMI ≥ 100%) — масштабировать;
- 🟡 0–100% — оптимизировать;
- 🔴 убыточная или без продаж при расходе ≥ среднего чека — резать или перестраивать.

Под таблицей: какая доля выручки сопоставлена (P4), учтён ли лаг продаж, что не сопоставилось и почему.

Нет продаж — одна строка: «Окупаемость не оценивалась: нет данных о продажах. С выгрузкой заказов с UTM аудит покажет, какие кампании реально приносят деньги».

## Главные проблемы

Три–пять пунктов, отсортированных по деньгам:

1. **<Проблема>** (<ID проверки>, порог: <порог>) — <цифры>. → <что сделать>.
2. …

## Подробно по категориям

### Метрика и цели
### Продажи и окупаемость
### Слив бюджета
### Структура и стратегии
### Ключевые фразы и запросы
### Объявления
### Таргетинг

В каждой категории: только WARN и FAIL. Для каждого пункта — что увидели, цифры, порог, что сделать. Статусы PASS — одной строкой «В порядке: …».

## Готово к копированию

**Минус-слова** (добавить на уровень кампании <название> или в общий набор):
```
-слив -складчина -торрент -госуслуги …
```

**Площадки для запрета** (кампания → Настройки → Запрещённые площадки):
```
example-game.com
com.example.flashlight
…
```

## Ограничения аудита

- Какие проверки не оценены (NA) и почему: нет отчёта, нет ответа, нет целей.
- Короткий период или мало данных.
- Если tCPL взят как средний CPL по аккаунту или рассчитан по формуле — сказать об этом.
- ROMI и ДРР по выручке, без маржи, налогов и комиссий платформ; свежие кампании (младше лага продаж) по продажам не оценивались.

Если UTM-разметки нет или она неоднозначная — вставь рекомендуемый шаблон UTM из чек-листа.
```
