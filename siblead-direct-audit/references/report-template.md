# Формат отчёта

Пиши для владельца бизнеса: простыми словами, с цифрами, без жаргона. Объясняй термины при первом упоминании, например: «РСЯ (реклама на сайтах-партнёрах Яндекса)». Не обещай рост заявок в процентах — показывай, сколько денег можно перестать терять.

```markdown
# Аудит Яндекс Директа

<Школа / эксперт / продукт> · реклама <дд.мм – дд.мм>, продажи <дд.мм – дд.мм> · данные: <выгрузки / API>, <продажи: источник или «без продаж»>

## Оценка: <N>/100 — <грейд> (<статус>)

<таблица категорий: категория | вес | балл | проблемы (FAIL) | замечания (WARN)>

<1–2 предложения: главное, что нужно знать.>

## Деньги

| | |
|---|---|
| Расход за период | … ₽ |
| Клики · CTR · средняя цена клика | … · …% · … ₽ |
| Регистрации · CPL · бюджет в месяц | … · … ₽ · ~… ₽ |
| Дошли до вебинара · цена дошедшего | … · … ₽ |
| Продажи · выручка · CAC (если есть продажи) | … · … ₽ · … ₽ |
| ROMI · ДРР (по выручке) | …% · …% |
| **Под риском (оценка)** | **~… ₽ (…% бюджета)** |

Из чего складывается «под риском»: нецелевые запросы ~… ₽, мусорные площадки ~… ₽, фразы и кампании без конверсий ~… ₽. Суммы не задваивай: одна и та же трата не должна попадать в две строки.

## Воронка

Только если есть данные воронки. Таблица «Воронка в целом»: шаг → количество → конверсия → цена шага, рядом — ориентир из чек-листа (🟢 в норме / 🟡 ниже / 🔴 сильно ниже).

Затем таблица по кампаниям: расход, клики, регистрации, конверсия сайта, ₽/рег, доходимость, ₽/дошедшего, заявки, продажи, CAC, выручка, ROMI. Отсортируй по расходу и отметь:
- 🟢 окупается (ROMI ≥ 100%) или лучшая цена дошедшего — масштабировать;
- 🟡 ROMI 0–100% — оптимизировать;
- 🔴 убыточная, без продаж при расходе ≥ среднего чека, или дешёвые регистрации с провальной доходимостью — резать или перестраивать.

Под таблицами — выводы (список ниже), доля сопоставленных данных, учтён ли лаг продаж.

Нет данных воронки — одна строка: «Воронка не оценивалась: нет данных о регистрациях и продажах. С выгрузками по шагам с UTM аудит покажет, какие кампании приводят людей, которые доходят до вебинара и покупают».

### Выводы по воронке и продажам

Дай столько из этих выводов, сколько позволяют данные. Каждый — с цифрами:

1. **Окупается ли Директ в целом:** выручка, ROMI, ДРР, CAC против среднего чека.
2. **Где главная потеря в воронке:** шаг с самой большой просадкой против ориентира. Реклама (регистрации дорогие или нецелевые), лендинг (конверсия сайта в регистрацию ниже 9%: оффер, первый экран, форма, скорость, соответствие объявлению), доходимость (ниже 30%: прогрев, напоминания, время вебинара, качество трафика), вебинар (заявки от дошедших), продажи (оплаты из заявок). Прямо скажи, что не связано с рекламой: такие правки в Директе не помогут.
3. **Какие кампании приносят деньги, а какие — только регистрации:** топ по ROMI и цене дошедшего против топа по расходу.
4. **Качество трафика:** кампании с дешёвой регистрацией и низкой доходимостью или конверсией в оплату (обычно РСЯ и автотаргетинг). Сколько денег в них уходит.
5. **Цена регистрации против цены продажи:** где оптимизация на дешёвые регистрации ухудшила CAC.
6. **Ключи, объявления и площадки с продажами** (если в метках есть utm_term, utm_content или {source}): что масштабировать, что отключить.
7. **Что перераспределить:** сколько бюджета снять с убыточных кампаний и куда переложить, с оценкой эффекта по текущему CAC. Только как оценка, без обещаний.
8. **Связка данных:** какая доля продаж и регистраций потеряла UTM, расходятся ли регистрации на платформе с конверсиями в Директе, передаются ли оплаты в Метрику. Что исправить, чтобы Директ оптимизировался на продажи.

## Главные проблемы

Три–пять пунктов, отсортированных по деньгам:

1. **<Проблема>** (<ID проверки>, порог: <порог>) — <цифры>. → <что сделать>.
2. …

## 1. Минус-фразы

По разделу «Что положить в отчёт» из `minus-words.md`: сколько денег ушло на нецелевые запросы, топ-10, блоки минус-слов по уровням (общий набор / кампания / группа), спорные запросы, запросы, которые стоит добавить в ключи.

## 2. Мусорные площадки

По `placements.md`: сколько денег ушло, топ-10, список для «Запрещённых площадок» по кампаниям, рабочие площадки, которые не трогать.

## 3. Структура кампаний

По `structure.md`: оценка текущей структуры, целевая структура деревом, план перехода без сброса обучения.

## 4. Цели

По `goals.md`: как сейчас, проблемы, как правильно по шагам.

## Готово к копированию

Все блоки для копирования из модулей 1 и 2 ещё раз, подряд, без пояснений: минус-слова по уровням и запрещённые площадки по кампаниям. Это то, что человек вставит в Директ сегодня.

## Ограничения аудита

- Какие проверки не оценены (NA) и почему: нет отчёта, нет ответа, нет целей.
- Короткий период или мало данных.
- Если tCPL взят как средний CPL по аккаунту или рассчитан по формуле — сказать об этом.
- ROMI и ДРР по выручке, без маржи, налогов и комиссий платформ; свежие кампании (младше лага продаж) по продажам не оценивались.
```
