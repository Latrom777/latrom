# Какие файлы нужны для аудита

Давай человеку по одному пункту, простыми словами. Если в сессии есть браузер, сначала предложи скачать всё самому (`browser-download.md`). Названия кнопок в Директе иногда меняются: если человек не находит пункт, попроси скриншот и подскажи по нему.

Общие настройки для отчётов Директа:
- **Период** — последние 30 дней (при небольшом бюджете — 60–90).
- **Формат** — XLSX или CSV.
- **Цели** — если есть выбор целей Метрики, выбрать основную: регистрация на вебинар, заявка, оплата.

## Из Директа

### 1. Статистика по кампаниям (обязательно)

«Статистика» / «Мастер отчётов».
- Срез: **Кампания** + **№ кампании** (ID обязательно — по нему сопоставляются регистрации и продажи).
- Столбцы: показы, клики, CTR, расход, средняя цена клика, отказы, конверсии, цена цели.

### 2. Поисковые запросы (если есть поиск)

Мастер отчётов → **Поисковые запросы**.
- Срез: запрос + кампания (+ условие показа, если можно).
- Столбцы: показы, клики, расход, CTR, отказы, конверсии.
- Скачать **все** строки, а не первую страницу.

### 3. Площадки РСЯ (если есть РСЯ или ЕПК)

Мастер отчётов → срез **Площадка** + кампания, тип площадки — сети.
- Столбцы: показы, клики, CTR, расход, отказы, конверсии.

### 4. Условия показа / ключевые фразы (желательно)

Срез: **Условие показа** + кампания + группа. Столбцы те же плюс средняя цена клика.

### 5. Возраст и пол, регионы (желательно)

Два небольших отчёта: срез **Пол + Возраст** и срез **Регион таргетинга**. Столбцы: расход, клики, конверсии, цена цели.

### 6. Структура: кампании, группы, ключи, минус-слова, объявления (важно)

Кампании → выбрать все активные → «Выгрузить в Excel» (или экспорт из Директ Коммандера). По этому файлу проверяются структура, текущие минус-слова (чтобы не дублировать) и объявления. Если сложно — скриншоты списка кампаний, групп одной основной кампании и 3–5 главных объявлений.

### 7. Настройки стратегий и цели (важно)

- Скриншот настроек стратегии 1–2 основных кампаний: стратегия, цель оптимизации, оплата за клики или конверсии, счётчик Метрики, ценность цели.
- Скриншот списка целей в Метрике (metrika.yandex.ru → счётчик → «Цели»).

По ним проверяется, на что учится Директ (модуль «Цели»).

## Воронка: регистрации → дошли до вебинара → заявки → продажи (очень желательно)

Без этих данных аудит видит только регистрации. В инфобизнесе дешёвые регистрации часто не доходят до вебинара и не покупают, поэтому с воронкой аудит намного точнее. Можно прислать не все шаги: даже одни продажи уже сильно помогают.

| Шаг | Откуда взять |
|---|---|
| Регистрации | GetCourse: пользователи или заявки с лендинга регистрации; Bizon365 / вебинарная платформа: список регистраций; Тильда; таблица лидов |
| Дошли до вебинара | Вебинарная платформа (Bizon365, GetCourse-вебинары и т.п.): зрители, лучше с временем присутствия |
| Заявки | GetCourse: заказы, созданные на вебинаре; AmoCRM / Bitrix24: сделки на этапе «заявка» и дальше |
| Продажи | GetCourse / Prodamus / платёжная система: оплаченные заказы; CRM: успешные сделки |

**Что нужно в каждом файле:**
- **UTM-метки** (utm_source, utm_campaign, по возможности utm_content и utm_term) — отдельными колонками или внутри ссылки регистрации. Без меток шаг посчитается только в целом, без разбивки по кампаниям.
- Для продаж — **сумма** (лучше «оплачено») и **статус**.
- **Email или телефон можно оставить** — по ним ассистент схлопнет дубли (человек зарегистрировался дважды). Сами контакты в отчёт не попадут. В отчёт они не попадут. Если не хотите отправлять контакты, удалите их: тогда дубли не схлопнутся, и ассистент об этом напишет.

**Форматы:** CSV/XLSX-файлы, ссылка на Google Таблицу (доступ «читатель по ссылке»), один файл CRM со всеми этапами (ассистент разобьёт его сам), уже сгруппированная таблица «кампания → регистрации / дошли / заявки / продажи», в крайнем случае скриншот или PDF.

**Период:** регистрации — тот же, что у рекламы; продажи — плюс 2–4 недели на прогрев и вебинары.

**GetCourse:** «Продажи» → «Заказы» → нужный период → «Экспорт», в настройке колонок добавить UTM-поля и «Оплачено». Для регистраций — «Пользователи» с фильтром по группе или форме регистрации и колонками UTM. Интерфейс может отличаться — ориентируйся по скриншоту человека.
