# Какие файлы нужны для аудита

Давай человеку по одному пункту, простыми словами. Названия кнопок в Директе иногда меняются: если человек не находит пункт, попроси скриншот и подскажи по нему.

Общие настройки для отчётов Директа:
- **Период** — последние 30 дней (при небольшом бюджете — 60–90).
- **Формат** — XLSX или CSV.
- **Цели** — если есть выбор целей Метрики, выбрать основную: регистрация на вебинар, заявка, оплата.

## Из Директа

### 1. Статистика по кампаниям (обязательно)

«Статистика» / «Мастер отчётов».
- Срез: **Кампания** + **№ кампании** (ID обязательно — по нему сопоставляются продажи).
- Столбцы: показы, клики, CTR, расход, средняя цена клика, отказы, конверсии, цена цели.

### 2. Поисковые запросы (если есть поиск)

Мастер отчётов → **Поисковые запросы**.
- Срез: запрос + кампания (+ условие показа, если можно).
- Столбцы: показы, клики, расход, CTR, отказы, конверсии.
- Скачать **все** строки, а не первую страницу.

### 3. Площадки РСЯ (если есть РСЯ или ЕПК)

Мастер отчётов → срез **Площадка** + кампания, тип площадки — сети.
- Столбцы: показы, клики, CTR, расход, отказы, конверсии.

### 4. Условия показа / ключевые фразы (желательно)

Срез: **Условие показа** + кампания + группа. Столбцы те же плюс средняя цена клика.

### 5. Возраст и пол, регионы (желательно)

Два небольших отчёта: срез **Пол + Возраст** и срез **Регион таргетинга**. Столбцы: расход, клики, конверсии, цена цели.

### 6. Объявления (желательно)

Кампании → «Выгрузить в Excel» (или экспорт из Директ Коммандера). Если сложно — достаточно скриншотов 3–5 главных объявлений.

## Продажи (очень желательно)

Без продаж аудит видит только регистрации. В инфобизнесе дешёвые регистрации часто не покупают, поэтому с продажами аудит намного точнее.

**Что подойдёт** — любой из вариантов:
- выгрузка заказов или оплат из **GetCourse**, Prodamus, Тильды, другой платформы — с колонками UTM;
- выгрузка сделок из **AmoCRM / Bitrix24** с полями UTM;
- **ссылка на Google Таблицу** с открытым доступом «читатель по ссылке»;
- готовый отчёт «продажи по utm_campaign» (кампания, количество, сумма);
- если ничего этого нет — скриншот или PDF отчёта по источникам продаж.

**Подсказки для человека:**
- Период продаж — тот же, что у рекламы, **плюс 2–4 недели** на прогрев и вебинары.
- Нужны колонки: **сумма** (лучше «оплачено»), **статус**, **UTM-метки** (utm_source, utm_campaign, по возможности utm_content и utm_term) или ссылка, в которой эти метки есть.
- **Контакты клиентов** (email, телефон, имя) не нужны — лучше удалить их перед отправкой. Если останутся, скрипт выбросит их сам и в отчёт они не попадут.

**GetCourse:** «Продажи» → «Заказы» → нужный период и статус → «Экспорт», в настройке колонок добавить UTM-поля (utm_source, utm_campaign и т.д.) и «Оплачено». Интерфейс может отличаться — ориентируйся по скриншоту человека.
