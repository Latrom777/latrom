# Модуль 2. Мусорные площадки РСЯ

Обязательная часть аудита, если есть РСЯ или ЕПК с показами в сетях. Обычно здесь уходит больше всего денег впустую. Решаешь ты сам, по названию площадки и цифрам вместе. Словарь в `audit-checklist.md` — подсказка. Кодом можно только отобрать площадки для разбора и посчитать суммы; решение по каждой площадке — твоё.

## Какие площадки разбирать

Из отчёта по площадкам (только сети):
1. **все** площадки с расходом ≥ 0.5 × tCPL;
2. **все** площадки с CTR >3% и ≥20 кликами;
3. затем по убыванию расхода, пока не покроешь ≥80% расхода сетей.

## Как классифицировать каждую площадку

Смотри одновременно на название и на цифры: клики, CTR, CPC, отказы, регистрации, а если есть воронка — дошедших и продажи по `utm_placement` / `{source}`.

| Класс | Признаки | Решение |
|---|---|---|
| **Мусор по смыслу** | игры, фонарики, обои, погода, кешбэк и купоны, VPN, «очистка телефона», читалки и пиратские книги, торренты, детские приложения, `.apk`; аудитория, которая точно не купит курс | запретить уже с ~5 кликов, не дожидаясь статистики |
| **Фрод / случайные клики** | CTR >5% при низкой конверсии; CTR >3% и 0 регистраций; CPC <3 ₽ и отказы >30%; мобильные приложения с огромным числом кликов и нулём результата | запретить |
| **Дорогая пустышка** | расход ≥2×tCPL и 0 регистраций (B3); или регистрации есть, но доходимость или продажи в разы хуже среднего | запретить; при 1–2×tCPL — кандидат, наблюдать |
| **Решать по цифрам** | отзовики, видеохостинги, агрегаторы курсов, новостные, Дзен и сервисы Яндекса, крупные медиа | по результату, не по названию |
| **Рабочая** | регистрации по цене ≤ tCPL, нормальная доходимость | оставить; лучшие — отметить как точку роста |

- Сначала смотри DSP и SSP и мобильные приложения (`com.*`, названия из магазинов приложений) — обычно основной мусор там.
- Дубли `www.` и без `www.` — одна площадка.
- Часть площадок (некоторые сервисы Яндекса) запретить нельзя — пометь это, если встретишь.
- Лимит запрещённых площадок в кампании — 1000: если список длинный, сначала самые дорогие.

## Что положить в отчёт

1. **Сколько денег ушло на мусорные площадки** (сумма и % расхода сетей) — это проверки B2 и B3. Рядом — правило отбора: «площадки с расходом от N ₽ и 0 регистраций за период». Сомнительные площадки — отдельным списком на ручную проверку, не в массовый запрет.
2. **Топ-10 площадок по потерянным деньгам**: площадка → расход → клики → CTR → регистрации → почему мусор.
3. **Блок для копирования** в «Запрещённые площадки» по кампаниям — по одной площадке в строке.
4. **Рабочие площадки**, которые нельзя трогать, и лучшие по цене регистрации.
5. **Профилактика:** раз в 1–2 недели повторять чистку; для новых кампаний сразу ставить базовый список запретов из найденного.
