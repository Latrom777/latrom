# Модуль 1. Минус-фразы

Обязательная часть аудита. Делаешь её ты сам, по смыслу. Не по подстроке и не скриптом: «бесплатный вебинар по Python» для школы с бесплатным вебинаром — целевой запрос, а «python курс слив» — нет, хотя оба могут совпасть со словарём. Словарь в `audit-checklist.md` — подсказка, о чём не забыть, а не правило. Кодом можно только отобрать запросы для разбора (по кликам и расходу) и посчитать суммы; сам разбор — ты, запрос за запросом.

## Что нужно знать до начала

Без этого запрос не классифицировать. Если не знаешь — спроси человека:
- что продаёт школа: продукт, тема, уровень, формат (онлайн / вебинар / курс / наставничество);
- что является оффером рекламы: бесплатный вебинар, лид-магнит, платный трипваер, сразу курс;
- для кого: новички или профи, B2C или B2B, страны и регионы;
- бренд эксперта или школы, бренды конкурентов: таргетируемся на них или нет.

## Какие запросы разбирать

Из отчёта по поисковым запросам:
1. **все** запросы с ≥5 кликами;
2. **все** запросы с расходом ≥ 0,5 × tCPL;
3. затем по убыванию расхода, пока не покроешь ≥80% расхода поиска.

Если запросов тысячи, разбирай партиями, но каждый из отобранных — прочитай. Не выводи заключение по первым 20 строкам.

## Как классифицировать каждый запрос

Для каждого запроса — один из трёх ответов с короткой причиной:

| Класс | Значит | Что делать |
|---|---|---|
| **Целевой** | человек может купить этот продукт через этот оффер | оставить; если есть регистрации или продажи, а запроса нет в ключах — добавить отдельной фразой |
| **Нецелевой** | не купит: ищет бесплатное или пиратское, работу, учёбу для вуза, чужой бренд, другой продукт, офлайн, другой город, информацию без намерения учиться | минусовать |
| **Спорный** | может быть целевым, зависит от оффера или данных | решать по базису качества: результат не хуже среднего — оставить; ≥25 кликов и 0 регистраций, или результат на базисе качества хуже среднего в 2+ раза при достаточном объёме — минусовать на уровне группы; иначе «наблюдать» |

Явный мусор (слив, складчина, торрент, «скачать курс») минусуй при любом числе кликов — это исключение из правила ≥5 кликов. Типовые нецелевые намерения в инфобизнесе: слив / складчина / торрент / «скачать курс»; бесплатные госпрограммы; вакансии и «работа» (но «как стать <профессия>» и «сколько зарабатывает <профессия>» для курсов профессий часто целевые — смотри по данным); рефераты, ГДЗ, ЕГЭ (если школа не про это); отзывы о чужих школах и «развод / обман»; конкретные чужие бренды; офлайн, очно, колледж, вуз; не та тема («python змея», «дизайн человека» для школы дизайна); слишком детский или слишком профессиональный уровень.

## Как формировать минус-слова

- **Минимальная форма.** Минусуй слово, которое делает запрос нецелевым («слив»), а не весь запрос. Минус-фразу из нескольких слов используй, когда отдельное слово резать нельзя («-бесплатно скачать» вместо «-бесплатно» у школы с бесплатным вебинаром).
- **Не режь целевое.** Для каждого минус-слова проверь все целевые запросы и ключевые фразы: не содержат ли они это слово. Если содержат — используй минус-фразу или операторы.
- **Операторы Яндекса:** `!слово` — точная словоформа; `+слово` — учитывать предлог или служебное слово (`-+для детей`); `"…"` и `[…]` — для фраз. Используй, только если без оператора заденешь целевые запросы.
- **Уровень:**
  - **общий набор минус-фраз** — универсальный мусор для всех кампаний (сливы, пиратство, госпрограммы, вакансии);
  - **кампания** — то, что нецелевое для её оффера или гео;
  - **группа** — кросс-минусовка: чтобы запрос попадал в одну правильную группу, а не в три сразу; и спорные запросы с ≥25 кликами без результата.
- **Не дублируй** уже стоящие минус-слова: сверь с выгрузкой минус-слов кампаний и групп, если она есть.
- У Яндекса есть лимиты на длину списка минус-фраз в кампании и группе: если список огромный — сначала самое дорогое, общий набор вынеси отдельно.

## Превентивный список

Даже без отчёта по запросам (или если он маленький) дай базовый минус-список для этой ниши: 20–40 слов, которые точно нецелевые для этого оффера. Отметь, что он превентивный, а не найден в данных.

## Что положить в отчёт

1. **Сколько денег ушло на нецелевые запросы** (сумма и % расхода поиска) — это проверка B1. Это измеренная утечка: расход нецелевых запросов за период.
2. **Топ-10 нецелевых запросов по расходу**: запрос → расход → клики → регистрации → почему нецелевой.
3. **Блоки для копирования** — отдельно по уровням:
   ```
   Общий набор:   -слив -складчина -торрент -госуслуги ...
   Кампания «…»:  -офлайн -очно ...
   Группа «…»:    -бесплатно скачать ...
   ```
4. **Спорные запросы** — коротким списком «наблюдать», с тем, какие цифры решат их судьбу.
5. **Целевые запросы с результатом, которых нет в ключах** — добавить (проверка K7).
