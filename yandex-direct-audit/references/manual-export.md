# Быстрый аудит: какие отчёты скачать из Директа

Давай человеку по одному отчёту, простыми словами. Названия кнопок в интерфейсе Директа иногда меняются — если человек не находит пункт, попроси скриншот и подскажи по нему.

Общие настройки для всех отчётов:
- **Период** — последние 30 дней (для маленьких бюджетов — 60–90, чтобы набралась статистика).
- **Формат** — XLSX или CSV.
- **Цели** — если есть выбор целей Метрики, выбрать основные (заявка, звонок, покупка). Без целей аудит получится только по кликам и отказам.

## 1. Статистика по кампаниям (обязательно)

Директ → «Статистика» / «Мастер отчётов».
- Срез (группировка): **Кампания**.
- Столбцы: показы, клики, CTR, расход, средняя цена клика, отказы, конверсии, цена цели (CPA), тип площадки (поиск/сети), если доступно.
- Скачать.

## 2. Поисковые запросы (обязательно, если есть поиск)

Мастер отчётов → **Поисковые запросы** (или в кампании «Поисковые запросы»).
- Срез: поисковый запрос + кампания (+ условие показа / ключевая фраза, если можно).
- Столбцы: показы, клики, расход, CTR, отказы, конверсии.
- Скачать **все** строки, не только первую страницу.

## 3. Площадки РСЯ (обязательно, если есть сети/РСЯ или ЕПК)

Мастер отчётов → срез **Площадка** (+ кампания).
- Фильтр: тип площадки — сети (если есть такой фильтр).
- Столбцы: показы, клики, CTR, расход, отказы, конверсии.

## 4. Ключевые фразы / условия показа (желательно)

Мастер отчётов → срез **Условие показа** (ключевая фраза) + кампания + группа.
- Столбцы: показы, клики, CTR, расход, ср. цена клика, отказы, конверсии.

## 5. Структура и объявления (желательно)

Чтобы проверить тексты объявлений, быстрые ссылки и уточнения:
- Директ → выбрать кампании → «Действия» / «Инструменты» → **«Выгрузить в Excel»** (Excel-выгрузка кампаний).
- Или Директ Коммандер → экспорт в XLS.

Если сложно — пропусти этот пункт, аудит объявлений сделаем по скриншотам 3–5 главных объявлений.

## Что спросить у человека словами

- Чем занимается бизнес и в каком городе/регионе работает.
- Что считается результатом: заявка, звонок, покупка — и сколько готовы за него платить.
- Есть ли Метрика и настроены ли цели.
- Кто ведёт рекламу: сам, фрилансер, агентство (влияет на тон рекомендаций).
