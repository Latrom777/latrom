# Чек-лист аудита Директа

Работай по данным из папки выгрузки. Каждая находка: **что не так → цифры → сколько денег под риском → что сделать**. Пороговые значения — ориентир; если у ниши другая экономика (дорогой B2B, редкие конверсии), скажи об этом и подстрой.

Перед началом выясни у человека (если не сказал): какая цель (заявки, продажи, звонки), допустимая цена заявки (CPA), подключена ли Метрика с целями. Без целей половина выводов — по косвенным метрикам (отказы, CTR), так и пиши.

## 0. Общая картина (`summary.md`, `report_campaigns.tsv`)

- Расход, клики, CTR, средняя цена клика, конверсии и CPA за период по аккаунту и по кампаниям.
- Распределение бюджета: какие 20% кампаний съедают 80% денег. Нет ли кампаний с расходом и нулём конверсий.
- Поиск vs РСЯ: где деньги и где результат (`AdNetworkType` в `report_placements.tsv`).

## 1. Структура и настройки кампаний (`campaigns.json`, `adgroups.json`)

- [ ] Поиск и сети в одной кампании (в `Settings`/стратегии показы на обеих площадках) — для классических кампаний лучше разделять; для ЕПК (`UNIFIED_CAMPAIGN`) проверь, что это осознанно.
- [ ] Стратегия: ручное управление при наличии целей и конверсий → кандидат на автостратегию с оплатой за конверсии; автостратегия без целей Метрики → оптимизирует клики, а не заявки.
- [ ] `CounterIds` пусто — нет счётчика Метрики. Критично: нет данных о конверсиях.
- [ ] `PriorityGoals` пусто при наличии счётчика — стратегия не знает, что считать результатом.
- [ ] Кампании в статусе отклонения/ограничения (`Status`, `StatusClarification`).
- [ ] Минус-слова на уровне кампании (`NegativeKeywords`) пустые у поисковых кампаний.
- [ ] Регионы групп (`RegionIds`) — нет ли показов «вся Россия» у локального бизнеса.
- [ ] Дубли: одинаковые ключевые фразы в разных группах/кампаниях одной цели (конкуренция с самим собой).

## 2. Ключевые фразы (`keywords.json`, `report_criteria.tsv`)

- [ ] Фразы с расходом ≥ 1–2 целевых CPA и без конверсий → снизить ставку / отключить / минусовать.
- [ ] Фразы с CTR на поиске ниже ~1–2% и заметным расходом → слабая релевантность объявления или фраза слишком общая.
- [ ] Однословные и слишком общие фразы без операторов (широкие ключи вроде «окна», «ремонт») с большим расходом.
- [ ] Фразы-«пустышки»: много показов, 0 кликов, или отключены/малый охват.
- [ ] Высокий процент отказов (`BounceRate` > ~30–40%) при большом количестве кликов → нецелевой трафик или плохая посадочная.

## 3. Поисковые запросы (`report_search_queries.tsv`)

Самый «денежный» раздел для поиска.

- [ ] Отсортируй по расходу. Отметь нецелевые запросы: бесплатно, скачать, своими руками, вакансии, отзывы (если не продаёте), б/у, конкуренты (если не таргетируетесь), не тот город, не тот товар.
- [ ] Посчитай деньги, ушедшие на явно нецелевые запросы, и долю от расхода поиска.
- [ ] Выдай готовый список минус-слов (одним блоком для копирования), сгруппированный по смыслу. Следи, чтобы минус-слова не резали целевые запросы.
- [ ] Отметь целевые запросы с конверсиями, которых нет в ключах → добавить отдельными фразами.

## 4. Площадки РСЯ (`report_placements.tsv`)

- [ ] Отсортируй по расходу сетевые площадки. Мобильные приложения и игры (`com.*`, названия игр), площадки с CTR аномально высоким (> 3–5% — часто случайные клики) или с отказами > 50%.
- [ ] Площадки с расходом ≥ 1 CPA и без конверсий.
- [ ] Посчитай, сколько денег ушло на такие площадки. Выдай список для «Запрещённых площадок» (кампания → настройки → запрещённые площадки).
- [ ] Если в РСЯ весь расход на 2–3 площадки — проверь, не приложение ли это со случайными кликами.

## 5. Объявления (`ads.json`)

- [ ] В группе одно объявление → нет тестирования. Рекомендация: 2–3 варианта (или используй мультиформат в ЕПК).
- [ ] Нет быстрых ссылок (`SitelinkSetId` пусто), уточнений/расширений (`AdExtensions` пусто), отображаемой ссылки (`DisplayUrlPath`), визитки/контактов (`VCardId` / привязка к Бизнесу) — объявления на поиске меньше и хуже по CTR.
- [ ] Объявления РСЯ без картинки (`AdImageHash` пусто).
- [ ] Нет второго заголовка (`Title2`).
- [ ] Ссылки (`Href`) без UTM-меток — при наличии сквозной аналитики/CRM это теряет данные. Ссылки, ведущие на главную, когда есть профильная посадочная.
- [ ] Отклонённые объявления (`Status` = REJECTED) и причины.
- [ ] Тексты: есть ли в заголовке ключ/суть запроса, есть ли УТП и призыв, цены/сроки/гарантии.

## 6. Бюджет и ставки

- [ ] Кампании, упирающиеся в дневной бюджет (`DailyBudget` маленький при хорошем CPA) — недополучают заявки.
- [ ] Наоборот, кампании без ограничений с плохим CPA.
- [ ] Средняя цена клика резко выше по нише без улучшения конверсии.

## Формат отчёта

```
# Аудит Яндекс Директа: <аккаунт>, <период>

## Итог в цифрах
Расход ... · Клики ... · CTR ... · CPC ... · Конверсии ... · CPA ...
Оценка денег под риском: ~... ₽ (…% бюджета) — нецелевые запросы ..., мусорные площадки ..., ключи без конверсий ...

## Главные проблемы (по деньгам)
1. <проблема> — <цифры> — <что сделать>
...

## Подробно
### Структура и настройки
### Ключевые фразы
### Поисковые запросы  (+ блок минус-слов для копирования)
### Площадки РСЯ       (+ список площадок для запрета)
### Объявления
### Бюджет и ставки

## План правок
| Приоритет | Что сделать | Где | Ожидаемый эффект |
| Сегодня | ... | ... | ... |
| На неделе | ... | ... | ... |
| Протестировать | ... | ... | ... |

## Ограничения аудита
(нет целей Метрики / не выгрузился отчёт X / короткий период и т.п.)
```

Пиши простым языком, без воды. Не обещай конкретный прирост заявок — давай оценку «сколько денег можно перестать сливать».
