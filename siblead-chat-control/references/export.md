# Как выгрузить рабочие чаты

Давай человеку по одному шагу. Нужен Telegram Desktop на компьютере — в мобильном приложении выгрузки нет.

## Вариант 1. Несколько конкретных чатов (проще)

Для каждого проектного чата:
1. Откройте чат в Telegram Desktop → меню «⋮» в правом верхнем углу → **Экспорт истории чата**.
2. Снимите галочки с фото, видео, голосовых, стикеров и файлов — нужен только текст.
3. Формат: **Машиночитаемый JSON**.
4. Период: например, последний месяц.
5. Пришлите файлы **result.json** из каждой папки. Можно все сразу.

## Вариант 2. Все чаты разом

1. Telegram Desktop → **Настройки** → **Продвинутые настройки** → **Экспорт данных из Telegram**.
2. Отметьте **Частные группы** (клиентские чаты обычно такие) и, если работаете в личке, **Личные чаты**.
3. Снимите медиа, формат **Машиночитаемый JSON**, задайте период.
4. Telegram может попросить подтвердить экспорт на телефоне, иногда он становится доступен через 24 часа.
5. Пришлите **result.json**. Проектные чаты выберем на следующем шаге.

## Если файл большой

- Сократите период до 2–4 недель — для контроля проектов этого достаточно.
- Заархивируйте в ZIP.
- Или выгружайте чаты по одному (вариант 1).

## Безопасность

Выгрузка содержит рабочую переписку. Она остаётся в аккаунте человека, скилл никуда её не отправляет и ничего не пишет в чаты.
